# toulmin

This is a Claude Code plugin marketplace with one plugin, toulmin. The plugin is a skill for building, planning and checking persuasive arguments with Toulmin's model.

## Installation

```
claude plugin marketplace add benjaminjackson/toulmin
claude plugin install toulmin@toulmin
```

Confirm with `claude plugin list`.

The skill is named `toulmin:toulmin`.

Evals live under `evals/`.
