# Writing the piece

Before you write, ask the user for what you are missing. Send one message with at most five questions, the most useful first. Ask only what would change the piece and what the request does not already answer. When the answers come back, write the piece as you normally would, and hand it over. When the user does not know something, write without it and do not guess.
